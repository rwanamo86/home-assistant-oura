# Privacy Policy

This application is a personal Home Assistant integration used only by the application owner.

The application accesses Oura data only for displaying and automating information inside the owner's private Home Assistant instance.

The application does not sell, share, or disclose Oura data to third parties.

Oura data is processed only for personal home automation purposes.

No public user accounts are offered and the application is not provided as a service to other users.

For questions regarding this application, contact the application owner using the email address registered in the Oura developer application.
